name: LIST detokenizes every keyword it was given
# README: "LIST — Print the program in detokenized form"
#
# The cheapest way to catch a keyword-table/token desync: a token whose entry
# has shifted lists as the wrong word, or as nothing. The README does not
# specify the detokenizer's spacing, so this asserts that each keyword comes
# back at all and on the right line, not how it is spaced — pinning the exact
# layout is a separate decision, and one the docs would have to make first.
mode: basic

> 10 FOR I = 1 TO 10 STEP 2
> 20 IF I > 3 THEN PRINT "X" ELSE GOSUB 100
> 30 NEXT I
> 40 DATA 1,2
> 50 READ A : RESTORE
> 60 DIM B(5) : POKE 4096,PEEK(4097)
> 70 ON I GOTO 10,20
> 80 REM DONE
> 90 END
> 100 RETURN
> LIST
~ ^10 FOR.*TO.*STEP
~ ^20 IF.*THEN.*PRINT.*ELSE.*GOSUB
~ ^30 NEXT
~ ^40 DATA
~ ^50 READ.*RESTORE
~ ^60 DIM.*POKE.*PEEK
~ ^70 ON.*GOTO
~ ^80 REM DONE
~ ^90 END
~ ^100 RETURN
